# Mnemo

自用的英语记忆卡片 PWA（Anki 式间隔重复，FSRS 排期）。手机优先，离线可用。

设计文档：`docs/superpowers/specs/2026-10-30-mnemo-design.md`
Mockup：`docs/mockups/mnemo-mockups.html`

## 地址就是数据的身份证

数据存在浏览器 IndexedDB，按 origin 隔离。生产地址是
`https://errax.github.io/mnemo/`。

- 不要改 GitHub 用户名，不要绑自定义域名——都会换 origin，旧数据留在旧地址里。
- 改仓库名只改路径，数据不丢，但需要同步改 `vite.config.ts` 里的 `base` 和 manifest。
- 本地开发（`pnpm dev`）和局域网预览的数据是一次性的，首页会有提示条。
- 真要换地址：先在设置里导出备份，再到新地址恢复。

## 功能

- 建卡：输入单词或短语，自动补音标和中文释义（ECDICT）；粘原句自动挖空，点词可改；一条记录可生成「中→英」「例句挖空」「英→中」三种卡
- 复习：FSRS 排期（ts-fsrs），四档打分带预计间隔，撤销，翻面自动朗读；每 20 张一个歇脚页
- 收集箱：多行粘贴 → 草稿 → 逐条建卡；整句草稿点词选要记的词
- 发音：有道在线 TTS + Service Worker 离线缓存，失败降级系统 TTS
- 卡片管理：勾选单词、全选搜索结果或整个词库，批量启用/关闭卡片类型，或删除单词；预览影响数量后确认
- 导入：Vocably CSV / TSV 预览后追加，已有词跳过，不改复习进度
- 备份：导出 JSON 到系统分享面板（存 iCloud Drive），从文件恢复
- 离线：PWA，加到主屏后无网可用

## 已知限制

- 有道发音是非官方接口，随时可能失效（会自动降级系统 TTS）
- 数据只在当前地址的浏览器里；换设备靠备份文件
- 没有多设备同步、牌组、统计

## 批量管理

在 **卡片 → 批量管理** 中，勾选单词，或使用「全选搜索结果」「选择整个词库」。全选包含未展示的结果，不受每次展示 300 条的限制；修改搜索条件会清除选择。

- **只去掉例句挖空卡**：选择单词 → 编辑卡片类型 →「例句挖空」设为「关闭」，其他类型保持不变 → 预览卡型修改 → 确认。保留单词、释义、例句及其他卡的复习进度，但删除挖空卡及其复习记录。
- **批量补建卡片**：把对应类型设为「启用」，只补建缺少的卡，不重置已有卡；不满足条件（如没有挖空例句）的卡会跳过并显示数量。即使关闭全部卡型，单词仍保留，可稍后重新启用；重新启用的卡从新卡开始。
- **清空词库后重新导入**：选择整个词库 → 删除单词 → 核对预览 → 确认删除。只删除单词及其卡片、复习记录，不清空收集箱、词典或设置。重新导入仍按现有导入规则自动生成卡片类型。

**删除不可撤销，建议先在设置中导出备份。** 所有批量修改整批成功或整批回滚；预览后所选数据有变化会要求重新预览。现有数据未记录导入来源，不能自动只选择 Vocably 导入的单词。

## 从 Vocably 导入

1. 在 Vocably 导出词库：列间选择 **Tab** 或 **Comma**，记录间选择 **New line**；保存下载的 `.csv` 文件，不必改扩展名。
2. 把文件存到 iPhone「文件」中，打开 Mnemo → **设置 → 导入词库**，选择文件。
3. 检查预览的新增 / 重复 / 无效数量，再点「导入 N 条」。

- 保留词头、中文释义、IPA 和各条例句；不保存英文 Definition、词性、时态等额外列，也不迁移旧复习进度。
- 自动生成中→英、英→中；例句能自动挖空时再生成挖空卡。所有新词按当前每日新卡上限开始学习。
- 已有词、文件内重复按「忽略大小写、去首尾空格」跳过，首条有效记录优先。不会覆盖已有释义或排期，不归并单复数。
- 空词头 / 中文释义的记录会显示序号并跳过。支持带引号的逗号、换行、转义引号；不支持 Vocably 自定义分隔符。每次最多 5 MB、10000 条。
- Vocably 导出页提示：2025-10-27 之前创建的卡无法导出；Mnemo 无法恢复导出文件中不存在的词。
- **导入词库仅追加；「从文件恢复」只认 Mnemo JSON 备份，会覆盖全部现有数据。两者不同。**

其他外部格式尚未接入；解析器按格式适配，新增格式不需要另做入库流程。

## 开发

```bash
pnpm install
pnpm dev          # http://localhost:5173/mnemo/
pnpm test
pnpm build
pnpm build:dict   # 重新生成词典子集（需要网络，下载 66 MB 的 ECDICT CSV）
```

## 部署

推 `main` 触发 `.github/workflows/deploy.yml`。GitHub 仓库 Settings → Pages → Source 选 **GitHub Actions**（只需做一次）。
