4. 设计规范

实现时照这个来。4pt 网格，屏幕左右内边距 16，卡片内边距 14。

颜色 · 浅色 / 深色

强调 #0071e3 / #0a84ff
背景 #f5f5f7 / #000
卡片 #fff / #1c1c1e
文字 #1d1d1f / #f5f5f7
次要 #86868b / #8e8e93
分隔 #e5e5e7 / #2c2c2e
挖空高亮 #fff3bf
忘了 #ffe5e3 / #c0392b
困难 #fff0d6 / #b7791f

简单 #e8f4fd / #0071e3
提醒条 #fff8e6

深色模式下四个打分色用同色相、12–18% 透明度的底 + 亮一档的前景。

中文 PingFang SC，英文 SF（系统自动）。输入框字号 ≥ 16 防 iOS 聚焦缩放。

圆角 / 尺寸

  • 卡片 / 分组 / 主按钮：14
  • 输入字段 / 提醒条：12 · 搜索框：10
  • 打分按钮：12 · chip / 徽标：全圆
  • 主按钮高 50 · 打分按钮高 52 · 列表行高 ≥ 44
  • tab bar 高 49 + 安全区 · FAB 52
  • 卡片不用阴影，靠背景色层级；只有 FAB 有阴影
  • 动效仅限翻面与页面切换
