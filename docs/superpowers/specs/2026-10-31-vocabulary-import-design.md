# 词库导入

## 意图与范围

用户要在 Mnemo 内直接导入外部词库；Vocably 是第一种支持的外部格式，不是离线转换脚本。此前已确认追加导入、重复跳过和字段/卡型映射，并要求继续实现，按这些决定直接执行。沿用 React、Dexie、FSRS 和离线 PWA，不引入服务端或改变数据库 schema。

## Approaches

- 转换为整库备份：容易但恢复会覆盖现有数据，不符合追加需求，排除。
- 通用手动列映射器：能兼容更多表格，但手机上操作复杂；当前不做。
- **已选：格式适配器 + 统一预览和追加入库。** 首个适配器识别 Vocably 的表头；后续格式增加适配器，不复制入库规则。Mnemo JSON 备份仍使用现有恢复入口，不作为追加导入。

## 已确认的规则

- 设置新增「导入词库」入口，与「从文件恢复」分开；只追加，不删除或修改现有词条、卡片和排期。
- 同词按现有 `headwordKey`（trim + lowercase）识别；已有词和文件内重复全部跳过，首个有效条目优先；不把单复数/变形归并。
- `Word/Phrase` → headword；`Translation` → meaning；`IPA` → phonetic；`Example` 按行拆分，去掉行首列表星号，每行一条例句。复用 `detectBlanks` 自动挖空。
- Definition、Part of Speech、时态、单复数列当前不保存，不自动查询词典覆盖用户文本。
- 有词头和中文的记录生成 zh2en、en2zh，有能挖空的例句再生成 cloze。新卡使用当前 FSRS 默认值，仍受每日额度限制，无复习历史。

## 实现者补充的安全细节

- 识别 Vocably 的 CSV（逗号）与 TSV（Tab），不凭 `.csv` 扩展名判断。UTF-8 BOM、CRLF、双引号转义及引号内换行由 `csv-parse` 浏览器构建处理，不用 split 换行解析 CSV。自定义分隔符暂不支持。
- 必需表头 Word/Phrase、Translation；IPA、Example 可缺省。空词头/释义行列为无效记录（以数据记录序号报告），导入前明确显示，默认跳过。结构损坏（如未闭合引号、列数不一致）整份拒绝，不静默丢列。
- 文件限制 5 MiB，最多 10,000 条数据记录。限制错误不写数据库。
- 选文件后先展示识别格式、总数、可新增数、重复数、无效数和前 5 个待新增词条；确认前不写库。文件读取/解析失败显示中文错误；全部重复/无效时禁用导入。
- 确认时在单一 Dexie rw(notes, cards) 事务中重新去重并写入：避免预览后库发生变化以及重复点击/并发导入创建重复词。异常整批回滚。导入不改变设置（包括最后手动选择的卡型）、草稿或备份时间。
- 成功展示实际新增词条/卡片数及跳过数。失败保留预览供重试。文件 input 可重新选择相同文件；操作期间禁用再次导入，异步状态在卸载后不继续提交。
- 成功后后台预热新词头发音，预热失败不撤销导入、不当成入库失败；不等待网络再显示成功。
- 用户提供的完整词库不提交到公开仓库；测试使用合成样例，真实 CSV 仅在本地额外验证。

## 验收

解析测试覆盖引号内换行、引号转义、逗号/Tab、BOM/CRLF、短语、无效和损坏记录、不支持的格式、数量限制。数据库测试覆盖去重、重复导入幂等、保留已打分卡、保留设置、全量回滚、预览后插入相同词和日额度。UI 测试覆盖预览不写库、确认导入、错误/重试、全重复禁用和设置入口。真实 CSV 应识别 113 条并保留其中文、IPA、例句。全套测试和生产构建通过后交付；发布需用户明确指示。
