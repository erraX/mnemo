## Design Specificity Verdict

**LLM assessment**：系统本身不特异——Apple 中性灰、一个蓝、系统字体栈、14px 卡、发丝线、「静止即扁平」，这套词汇任何习惯追踪或笔记应用都能原样穿走。真正有作者的只有三处：复习卡面（一张卡、一个动作、四档 tint 各自带间隔预览、「想好了再翻」）、20 张节奏的歇脚/完成这一对屏、以及会自述后果的建卡器（「保存 · 生成 3 张卡」「已从词典补全 / 词典没有，手动填写」）。其余的今日页、设置列表、搜索行列表、tab bar，都是 Anki / Quizlet / Mochi 可以不改一字就上架的品类家具。

产品特异（真的为这个产品长出来的）：`GradeBar.tsx` 四档 tint + 间隔微标签；`BreatherPage.tsx`「☕ 已复习 20 张 / 还剩 N 张」+「今天到这」；`DonePage.tsx` 只有三个数字、无 streak 无 confetti；`noteForm.ts` 的「保存 · 生成 3 张卡」与 `NoteEditor.tsx:136` 的词典来源提示；`Inbox.tsx:14` 的「像是句子 · 点一个词作为要记的词」与「可直接存 / 待补全」；`Today.tsx:17` 把备份说成时间（「上次备份是 9 天前」）；`BulkNoteActions.tsx:113` 的「被关闭卡片的复习进度将永久删除，不可撤销」。

品类通用（无主）：tab bar 三个空心圆角方块（`TabBar.tsx:24`，无字形、无映射，去掉中文标签任何一屏都认不出来）；今日页 = 大数字卡 + 主按钮 + 一行 + FAB，与「20 张新卡、离线、04:00 边界」毫无关系；所有单条破坏性操作都走 `window.confirm`；设置页把 `Spike 1 · 有道音频离线缓存` / `Spike 2 · 系统 TTS`（`Settings.tsx:162-165`）抬到「备份到文件」同级。

**结论**：一个纪律很好的 iOS 外壳，包着两处真正有作者的瞬间（复习循环、批量预览的安全模式）。把中文换成英文，约七成像素可以冒充 Mochi。

**Deterministic scan**：`.pi/skills/impeccable/scripts/impeccable detect --json src index.html` → exit 0，**2 条 advisory / 0 primary**，全部来自 `design-system-font-size`：`src/components/review/GradeBar.tsx:19` 的 `text-[13px]`、`src/screens/Cards.tsx:148` 的 `text-[9px]`。0 误报。

但 exit 0 **不等于干净**：扫描器自己的 stderr 写明「94 files scanned with regex matching only (.css, .ts, .tsx)。需要解析页面的规则（tiny-text、low-contrast 等元素规则）没有运行；finding 是下界，不是体检合格」。实测确认：`design-system-radius` 与 `design-system-color` 在 `rounded-md`/`rounded-lg`/`rounded-sm`、`text-xl`/`text-lg` 上全部漏报（Tailwind 刻度工具类逃过了三条 design-system 规则），`shadow-sm` 同样未触发。这 2 条 advisory 里，`Cards.tsx:148` 的 9px 低于 DESIGN.md 的 micro 10px 下限，是真问题；`GradeBar.tsx:19` 的 13px 与 DESIGN.md 散文「评分按钮主标签 14px/600」冲突，也是真问题——两条都指向「面上写着 14/10，代码里是 13/9」。

## Overall Impression

克制是真的，不是装出来的：没有渐变、没有第二强调色、没有 3D 翻面、没有 confetti，四档 tint + 间隔预览是全应用唯一一次「把后果写在按钮里」。产品的中段（翻面→评分→歇脚→完成）有一致的节奏感，「今天到这」是整份文案里最温暖的一句。

但两件事同时错了方向：**首页在讲引擎，不讲今天**（128ms 的词典耗时占着最贵的一屏），以及**越常见的破坏性操作越不安全**（一次误触取消毁掉刚填的卡，而一年一次的批量删除反而有完整预览）。最大的机会不是加东西，是把已经在 `BulkNoteActions` 里写对的模式，复制到其余三个破坏性路径上。

## What's Working

1. **`src/components/review/GradeBar.tsx`** —— 固定顺序、四档 tint、52px、间隔预览长在按钮里、写入时 `disabled:opacity-40`。整个决策落在拇指下，后果在承诺前可见。这就是产品本身。
2. **`BreatherPage.tsx` + `DonePage.tsx`** —— 72px 的 ☕ / ✓，一屏一句话，「今天到这」「再学 10 张新卡」。有节奏、不游戏化，并且承认 20 张是目标而不是下限。
3. **`BulkNoteActions.tsx:99-122`** —— 唯一完整实现了产品原则 5 的破坏性流程：数量 → 后果 → 不可撤销 → 建议先备份 → 确认按钮上带数字。其余三条破坏性路径都该照它重写。

## Priority Issues

### [P0] 取消一次，丢掉整张刚填的卡
`NoteEditor.tsx:157` → `SheetHeader.tsx:9`。退出路径是裸 `goBack`，无脏检查、无确认、无草稿暂存。这张屏由右侧 52px FAB 打开，而「取消」是 sticky header 最左侧的靶子——正好是误触拇指的落点。输入一个词、一句释义、两个例句之后，一次点击全部消失，没有 toast 也没有撤销。
**Why it matters**：直接违反产品原则 3（数据安全靠可见、可回滚的动作），并且精准杀死 PRODUCT.md 里写明的「碎片时间建卡」人格——那个人本来就随时会被打断。
**Fix**：`form.headword || form.meaning || form.examples.some(e => e.text)` 为真时，弹 Caution Paper 的确认（「这条卡还没保存」+ 保存为主按钮 + 放弃为次级），不走 `window.confirm`。
**Suggested command**：`/impeccable harden`

### [P1] 四个最要命的动作共用一个 `window.confirm`，而一年一次的批量删除有完整预览
`NoteEditor.tsx:106`（保存时删除卡型）、`NoteEditor.tsx:121`（删除记录）、`Inbox.tsx:63`（删草稿）、`Settings.tsx:89`（恢复备份）。四件事同时出问题：iOS 会在最紧张的时刻把 `errax.github.io` 印进弹窗，整块「像原生 app」的幻觉当场破功；单条删除不给任何数量，而批量路径会告诉你删了几张卡、几条复习记录——同一个模型，两套真相；恢复备份一次点击覆盖整库且不先自动导出；`toLocaleString()` 把 `2026/10/30 14:03:22` 这种非中文格式塞进中文句子。
**Why it matters**：破坏性操作的「恐惧等级」应该随发生频率和不可逆性上升，现在是乱的：越少发生的越被尊重，越常发生的越粗暴。
**Fix**：抽一个 `ConfirmSheet`，直接按 `BulkNoteActions` 的预览模式做。单条删除：「1 个单词 · 3 张卡 · 47 条复习记录 · 不可撤销」。恢复备份：强制先「导出当前数据」或自动落一份安全文件，成功后用 `good-fg` 报「已恢复 312 条记录」，不要和「已备份」共用一句 12px 灰字（`Settings.tsx:151`）。
**Suggested command**：`/impeccable harden`

### [P1] 首页最贵的一屏，花三分之一在讲词典加载用了 128 毫秒
`Today.tsx:80-86`。三行内部状态常驻：`正在准备词典… 40 / 60`、`词典已就绪：18432 条，用时 128 ms（下载 42 / 写入 86）`、`词典加载失败：{dict.error}`。128ms 是给作者看的，它却和「上次备份是 9 天前」——唯一真正重要的一句——共用同一个 12px 灰；它下面紧接着「共 N 条记录」，于是首页底部三分之一是纯噪声。而空态时首屏更冷：`0 / 0`、禁用态按钮上写着「今天没有要复习的」（把奖励态画成了坏掉的控件）、「没有待处理的」、「共 0 条记录」，唯一去处是一个裸 `+`。
**Why it matters**：这是每天打开的第一屏，也是唯一一次「打开就知道该干什么」的机会。现在它在回答「引擎怎么样了」，而不是「今天要做什么」。
**Fix**：删掉 ready/ms 分支；保留真正的加载态与一句人话失败（「词典加载失败，建卡时不会自动补全释义 · 重试」）。遥测挪到 设置 → 诊断，和两个 Spike 放一起。空态把 50px 主按钮换成「粘一段原文开始」的入口。
**Suggested command**：`/impeccable distill`

### [P1] 次要文字对比度不足，而最该看清的那个数字是最糊的
`--color-muted: #86868b` 在 `#ffffff` 上 = **3.5:1**，在 `#f5f5f7` 上 = **3.4:1**，低于 12–15px 文字所需的 4.5:1：日期、待复习/新卡标签、「想好了再翻」、到期日、例句来源、备份提醒、每一个设置项右侧的值、每一句导入提示，全在此列。最糟的是 `GradeBar.tsx:22`：间隔预览是 `text-[10px] font-normal opacity-75` 压在 tint 底色上——`#1e8449` 以 75% 叠在 `#e3f6e8` 上约 **2.8:1**，10px。那正是「记得 vs 简单」会怎样改变明天的唯一数字，却是全产品最看不清的一串。
**Why it matters**：这不是审美问题。间隔预览是产品唯一「把后果写在按钮里」的地方，看不清就等于没有。
**Fix**：muted 收到 `#6e6e73`（白底 4.6:1），去掉 `opacity-75`，间隔提到 11px 并使用全强度 `*-fg`；`Cards.tsx:148` 的 9px 提到 10px；`GradeBar.tsx:19` 按 DESIGN.md 散文改回 14px。
**Suggested command**：`/impeccable typeset`（配合 `/impeccable audit` 验收）

### [P2] 卡片批量管理：9 个控件同时在场的三明治
`Cards.tsx:107-125` + `BulkNoteActions.tsx:66-122`。sticky 面板里有 退出批量管理 / 全选搜索结果（N）/ 选择整个词库 / 清除选择；第二个面板 编辑卡片类型 / 删除单词；第三个面板 3 个 `<select>` + 图例 + 预览按钮；预览面板的「确认删除 N 个单词 / 取消操作」出现在这全部之下，可能已经滚出屏幕。破坏性动作与良性动作在视觉上同级。
**Why it matters**：这是全应用选项最多、后果最重的决策点，也是「≤4 个可见选项」失效最彻底的地方（最多 9 个可交互元素 + 9 个子选项）。
**Fix**：收敛成一个状态机、一个面板。选择态 = 单条 sticky 栏（已选 N · 编辑卡型 · 删除 · 清除）；「删除单词」只在预览 sheet 里出现，Caution Paper，贴安全区上浮。
**Suggested command**：`/impeccable distill`

## Persona Red Flags

**长期使用的作者，夜里单手复习 20 张**：打错一档要去右上角 400px 外够「撤销上一步」，且第一张卡时它是禁用且无解释的；没有 1–4 键、没有滑动；从复习栏点「编辑」会让 `sinceBreather` 归零（`initialSession()`），20 张节奏悄悄重启且界面上没有任何「已复习 N / 20」能察觉；`每日新卡上限` 是 32px 的 ±5 小方块（`Settings.tsx:106`），恰好在你落后、最想一次点到位的时候要连点六次。

**唯一合法的首次使用者（新 origin，或「从文件恢复」之后）**：首页给出 `0 / 0`、写着「今天没有要复习的」的死蓝按钮、「没有待处理的」、「共 0 条记录」，还有可能是原始 `dict.error`。唯一入口是一个 `+`；点进去是六字段表单、10px 大写标签、重名检测、整句选词器和八个标签 chip，而全应用没有一张「好卡长什么样」的示例。唯一的说明文字是 Import 的「支持的格式」长文——那是文档，不是引导。

**在碎片时间用 iPhone 加卡的作者（PRODUCT.md 写明的核心场景）**：真实的管线是 Mac 复制 → 通用剪贴板 → 收集箱多行粘贴 → 逐条建卡。但首页最大的蓝色物体是 `+` FAB——它**跳过收集箱**直开单卡编辑器，而收集箱只是一行白底列表、副标题「0 条待处理」。UI 把通用路径抬到了专属路径之上。进编辑器后，音标、标签、「卡片类型（多选）」在打出第二个字之前就已到场，保存没有任何确认，`goBack()` 回到首页既无 toast 也无回执——一天要做好几次的动作，一次收尾都没有。

## Minor Observations

- **圆角漂到六个值**：`rounded-lg`(8px) `Settings.tsx:114`、`BulkNoteActions.tsx:81,100`；`rounded-md`(6px) `TabBar.tsx:24`、`Settings.tsx:116`；`rounded-sm`(4px) `ClozeEditor.tsx:15`、`ClozeText.tsx:13`、`NoteEditor.tsx:177`；`Cards.tsx:148` 裸 `rounded`。DESIGN.md 的三半径规则（14/12/10/pill）在代码里有六个例外。
- **第三个阴影现场**：`Settings.tsx:116` 给选中的 美音/英音 药丸加了 `shadow-sm`，正是 Flat-By-Default 点名的那条违规。
- `Button.tsx:7` 硬编码 `text-white`；`BulkNoteActions.tsx:117` 用 `bg-again-fg` 当主按钮底色——深色模式下 `--color-again-fg` 变成 `#ff6961`，最破坏的那次点击成了白字压珊瑚色，约 2.8:1。
- `Import.tsx:92` 手搓了一个 `<label>` 当主按钮（`min-h-11` + `py-3` ≈ 56px，不是 50px 的 `Button lg`），并且是全应用唯一用 `focus-within:ring-2 ring-offset-2` 自定义焦点环的地方——绕开了 `Button`，也违背了「不用自定义焦点环」。
- `Review.tsx:190-197`：翻面容器是 `role="button"` + `aria-label="翻面"` + `outline-none`。aria-label 覆盖了整棵子树，读屏只会念「翻面，按钮」，**正在被考的词或句子永远读不到**；翻面后容器卸载，焦点丢失；`Review.tsx:219` 的 toast 没有 `aria-live`。
- 低于 44pt 的点击区：`NoteEditor.tsx:200` 的 `h-8 w-8` 发音键（同一个动作在 `CardFront.tsx:16` 是 `h-11 w-11`）、`Settings.tsx:106/108` 的 32px 步进器、`Settings.tsx:116` 约 26px 的段控件、`Settings.tsx:128` 24px 开关、`NoteEditor.tsx:234` 约 22px 标签 chip、`Inbox.tsx:97` 的 ✕、`TabBar` 的 anchor 约 42px（`pt-2` 挂在了 `<nav>` 上而不是链接上）。
- **Tab bar 是三个没有字形的方块**（`TabBar.tsx:24`）：未选中是 `#e5e5e7` 压在白色上（1.2:1），深色下 `#2c2c2e` 压在 `#1c1c1e` 上。三个 tab 的每日工具，唯一的常驻导航线索是 10px 中文。同时那 24px 饱和蓝方块是全应用最大的一块 Signal Blue，用在信息量最低的元素上。给个字形，或缩成 8px 圆点让字重承担状态。
- `DonePage` 三个数字来源不一：`reviewed` 来自 DB，`minutes` 来自 `elapsedMinutes(session)`（`session.ts:56`，自挂载起的墙钟）——页面开着去吃个午饭就报「43 分钟」。峰值屏上的伪造数据是最便宜的失分方式。
- `Import.tsx:84` 的 `<h1>` 少了其他 30px 标题都有的 `tracking-tight`；`Placeholder.tsx` 对用户显示「第二阶段实现」；`OriginBanner` 在非生产 origin 时占据首页最顶部、标题之上。
- 空态毫无统一形状，且都没有动作：「收集箱是空的」「还没有记录」「今天没有要复习的」「记录不存在」——三个死胡同加一个禁用按钮。

## Questions to Consider

1. 如果把所有中文标签删掉，哪一屏还能认出是 Mnemo？tab bar 会是三块灰方块，今日页会是一张数字卡，只有 ☕ / ✓ / 四档 tint 能活下来。那算一套系统，还是一张样式表？
2. 首页只允许说一句话——「今天 12 张待复习，20 张新卡」。为什么要花三分之一句去说词典 128ms 加载完？
3. 这个产品里每个破坏性操作要付不同数量的恐惧：批量删除有数量、有警告、有备份建议；删一条记录只有一个弹着 `errax.github.io` 的原生 alert。哪个你其实做得更频繁？
4. 如果 20 张歇脚是设计的情感脊柱，为什么界面从不告诉你现在是第 7 张——而点一次「编辑」就把计数清零了？
5. 产品写明的采集路径是 Mac→手机的剪贴板多行粘贴。首页最大的蓝元素却打开一个单词表单。设计到底相信哪一个？
